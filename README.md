# Algoritma Sorting — contoh kode

Semua file pakai array yang sama: [5, 2, 9, 1, 7, 3], dan mencetak setiap perubahan array.

Cara menjalankan (buka Terminal di folder ini):

    python3 bubble_sort.py
    python3 selection_sort.py
    python3 insertion_sort.py
    python3 merge_sort.py
    python3 quick_sort.py
    python3 bandingkan.py      # tabel jumlah perbandingan untuk n = 10, 100, 1000

| File              | Kompleksitas                          |
|-------------------|---------------------------------------|
| bubble_sort.py    | O(n²) (terbaik O(n) kalau sudah urut) |
| selection_sort.py | O(n²) selalu                          |
| insertion_sort.py | O(n²) (terbaik O(n) kalau sudah urut) |
| merge_sort.py     | O(n log n) selalu                     |
| quick_sort.py     | O(n log n) rata-rata, O(n²) terburuk  |
